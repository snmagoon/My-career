## Overview
A custom-built survey product for gathering information and presenting it in an organised way, applicable across many business disciplines. Features include geo-location, management of resources and events, live location of submitted data per event or activity, and analysis reports based on participants' answers. It spans a web portal, backend processes, and a mobile application.

- Designed and developed the mobile application.
- Built REST APIs to expose data, added features, and fixed bugs.
