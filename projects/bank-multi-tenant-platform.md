## Overview
A very large-scale, multi-tenant, configurable web platform (ASP.NET MVC) with backend processes. It manages survey- and rating-based scores assigned to each branch user, role-based separation between the portal and mobile app, report generation that follows the organisation's hierarchy, and direct Active Directory integration.

- Implemented tenant-specific requirements and resolved tenant-specific issues in the core system.
